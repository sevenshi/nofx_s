## 6. 六层止损体系（v19强化版）

### Layer 1：硬性止损（绝对底线）

**做多**：入场价 × (1 - 1.0%)
**做空**：入场价 × (1 + 1.0%)

**5000U资金示例**：
- BTC入场@$60,000，名义1200U，止损@$59,400，最大亏损$600/BTC × 0.015BTC = **$9 ≈ 0.18%**
- 占净值比例：9U / 5000U = **0.18%**（符合≤1.0%要求）

**触发条件**：价格触及立即市价平仓，无例外

### Layer 2：ATR动态止损（主力）

**基础公式**：
- 做多止损 = 入场价 - 1.5×ATR_1H
- 做空止损 = 入场价 + 1.5×ATR_1H

**时段调整（v19新增）**：
```
06:00-10:00（亚洲早盘）：标准 -1.5×ATR
10:00-18:00（欧美重叠）：收紧 -1.3×ATR（流动性最好）
18:00-22:00（美盘尾盘）：标准 -1.5×ATR
22:00-06:00：禁止开仓（无需设置）
```

**超卖超买区特殊**：
- 1H RSI<25或>75开仓时：固定-1.2×ATR（收紧25%）

**最小止损**：0.5%（提高至0.5%，原0.3%）

### Layer 3：时间止损（防僵尸单）

**标准持仓时限**：
- 第12周期（60分钟）未达浮盈1.0% → 平仓50%仓位
- 第18周期（90分钟）未达浮盈1.5% → 全部平仓

**超卖超买区特殊**：
- 第7周期（35分钟）未达浮盈1.0% → 全部平仓（快速止血）

**豁免条件**：
- 浮盈≥1.0%时，转由Layer 4浮盈止盈接管（取消时间限制）

### Layer 4：浮盈分段止盈（让利润奔跑）

**阶段1：浮盈1.0-2.0%**
- 平仓30%仓位（锁定0.3-0.6%净利润）
- 剩余70%仓位移动止损至入场价+0.3%（保本+）

**阶段2：浮盈2.0-3.5%**
- 再平仓30%仓位（累计平60%）
- 剩余40%仓位移动止损至入场价+1.2%（锁定1.2%利润）

**阶段3：浮盈≥3.5%**
- 剩余40%仓位设置移动止盈：回撤30%平仓
- 例：浮盈4.0% → 回撤至2.8%时平仓（锁定2.8%）

**预期效果**：
- 小盈利单（1-2%）：快速止盈避免回吐
- 大盈利单（3%+）：让利润充分奔跑，单笔可覆盖2-3次小亏

### Layer 5：市场结构突变（紧急）

**触发条件**：
1. **成交量萎缩突变**：5M成交量连续3根下降≥25%
2. **逆向信号出现**：持多仓时15M MACD死叉 + RSI跌破50
3. **L/S比率突变**：15分钟内变化≥0.8（如3.2→2.4）

**执行操作**：
- 立即减仓50%（部分止盈/止损）
- 剩余50%收紧止损至-0.8%（从-1.5%收紧）
- 禁止该币种4小时内再次开仓

### Layer 6：防御模式熔断（账户级）

**触发条件（任一满足）**：
1. 单日亏损≥3%净值（当前1.3U）
2. 连续2日累计亏损≥5%
3. 单日触发≥3次止损
4. 净值跌破35U

**执行操作**：
- 立即平掉所有持仓（无论盈亏）
- 暂停交易24-72小时（根据严重程度）
- 强制复盘分析亏损原因
- 解禁条件：人工确认策略无BUG + 情绪冷静

**快速解禁组合（v19保留但谨慎化）**：
- 解禁后第一笔必须Confidence≥95 + 最小杠杆1x + 最小仓位（名义10U）
- 第一笔盈利平仓后，第二笔才可恢复标准参数

### 7.5 手续费监控（新增核心功能）

**月度手续费上限**：净值的1.5%

- 按双边0.1%计算 → 月最大名义交易量75,000U

- 折算每日≤2.5次，策略限制3次符合

**实时监控**：
```python
每笔交易后计算：
  当月累计手续费 = Σ(名义价值 × 0.001)

  if 当月累计手续费 > 净值×2.5%:
      发出警告：接近手续费上限

  if 当月累计手续费 > 净值×3%:
      触发强制休息至月底
```

**日间（06:00-22:00）**：
- 记录最近20次API调用延迟
- 缓冲延迟 = μ + 1.5σ
- 预期范围：300-500ms

**夜间（22:00-06:00）**：
- 虽禁止开仓，但记录平仓操作延迟
- 缓冲延迟 = μ + 2.0σ
- 预期范围：500-800ms

### 8.2 信号确认等待机制（新增P1方案）

**标准流程**：
```
T0时刻：5M K线收盘，触发信号（如15M RSI=37）
↓
等待下一根5M K线开盘（延迟5分钟）
↓
T5时刻：重新验证信号仍然有效
  - 15M RSI是否仍≤38？
  - 5M MACD是否仍为金叉？
  - 1H趋势是否仍为多头？
↓
若全部满足 → 执行开仓
若任意不满足 → 取消信号
```

**优势**：
- 过滤70%假信号（瞬间脉冲造成的误判）
- 虽晚5分钟入场，但避免追高/追跌
- 延迟问题转化为信号验证时间

### 8.3 限价单预挂策略（可选P0方案）

若你后续学会实现限价单，可升级为：
```
信号预判阶段：15M RSI接近40但未触发
↓
提前挂限价买单：当前价-0.4%
↓
设置有效期5分钟
↓
若成交 → 验证信号 → 持仓
若未成交 → 自动撤单 → 放弃
```

当前v19保持市价单模式，配合确认等待机制即可。

## 9. 实战执行SOP（标准作业程序）

### 9.1 每日开盘前检查（05:55执行）

```
□ 检查净值是否≥35U（低于熔断线）
□ 检查昨日盈亏，连续2日亏损→暂停交易
□ 确认今日不是周日（周日禁止交易）
□ 检查SOL/DOGE冷却状态，确定今日交易币种池
□ 查看BTC大盘是否有重大消息（影响山寨币）
□ 确认NOFX系统API连接正常，延迟<500ms
□ 设置当日交易计数器归零
```

### 9.2 信号触发时执行（2分钟内完成）

```
1. 记录信号触发时刻和参数（T0）
   - 币种、方向、15M RSI、5M MACD状态等

2. 等待下一根5M K线开盘（T5）
   - 期间不执行任何操作

3. 重新验证信号有效性（T5）
   - 15M RSI仍在阈值内？
   - 5M MACD仍保持叉向？
   - 1H趋势未反转？

4. 计算Confidence评分
   - 必须≥92分才执行

5. 检查开仓限制
   - 当日开仓次数<2？
   - 当日未触发过止损？
   - 不在夜间时段？
   - 币种未处于冷却？

6. 全部通过→下单
   - 市价单开仓（指定名义价值12-15U）
   - 立即设置止损OCO（-1.5×ATR_1H）
   - 立即设置初始止盈（+2.5%）
   - 更新当日计数器+1

7. 记录到交易日志
```

### 9.3 持仓期间监控（每5分钟）

```
□ 检查是否触及六层止损任一条件
□ 更新浮盈状态，判断是否进入分段止盈
□ 监控成交量是否突然萎缩（Layer 5）
□ 检查持仓时长，是否接近时间止损阈值
□ 如出现逆向强烈信号，考虑提前减仓50%
```

### 9.4 每日收盘后复盘（22:05执行）

```
□ 统计当日交易次数、胜率、盈亏
□ 计算当日手续费消耗（名义交易量×0.1%）
□ 更新币种冷却状态（如有连续亏损）
□ 检查是否触发防御模式（单日亏损≥3%）
□ 记录典型案例（成功的/失败的），分析原因
□ 调整明日币种池（如需轮换）
□ 备份策略参数和交易日志
```

### 9.5 每周日复盘（全天）

```
□ 统计本周总盈亏、胜率、最大回撤
□ 计算本周手续费占比（应≤净值0.75%）
□ 分析哪个币种表现最好/最差
□ 检查Confidence阈值是否需要调整
□ 评估ATR止损是否过宽/过紧
□ 决定下周币种池配置
□ 若净值增长≥10%，考虑提取部分利润（保持50U基准）
□ 若净值下降≥10%，评估是否暂停策略优化
```
